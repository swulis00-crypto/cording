# 게임 단계 구성

KDC 탐험대는 4개 게임 단계로 구성한다. "넓게 → 깊게 → 작가 → 실제 서가" 순서로, 마지막 단계에서 분류기호와 저자기호를 합쳐 청구기호를 완성한다.

| 게임 단계 | 이름 | 배우는 것 | 상태 |
|---|---|---|---|
| 1 | 지식 구역 탐험 | KDC 주류 10개 (000~900), 20문제 여정 | 완성 (문항 검토 대기) |
| 2 | 번호 속 비밀 풀기 | 분류기호 둘째·셋째 자리의 규칙 4개, 15문제 | 완성 (문항 검토 대기) |
| 3 | 저자기호 만들기 | 저자기호를 만드는 방법과, 저자기호 순서 = 저자 이름 가나다순이라는 의미 | 설계 |
| 4 | 책 주소 완성하기 | 청구기호 = 별치기호 + 분류기호 + 저자기호 + 권차기호 + 복본기호 | 설계 |

- 청구기호는 책이 서가의 어디에 사는지 알려 주므로 게임에서는 **"책 주소"**라고 부른다.
- 단계 열림: 이전 단계를 마치면 다음 단계가 열린다. 마친 단계는 언제든 다시 할 수 있다. 미리보기 모드(`?preview=1`)에서는 모든 단계가 열린다.
- 분류는 KDC 제6판 원칙을 따른다. 예: 한국 소설의 시대 구분은 2000년 이후 작품을 813.7로 한다.
- 화면의 주류 색은 한국십진분류표 라벨 색상을 쓴다 (`src/index.css`의 `--c0` ~ `--c9`).

## 게임 1단계: 지식 구역 탐험

- 000 → 100 → … → 900 순서로 구역마다 2문제, 모두 20문제를 **이어서** 푼다. 구역이 바뀌어도 지도로 돌아가지 않고 바로 다음 문제로 넘어간다.
- 구역당 문제: ① 도서관 손님 부탁(주제 → 분류) ② 도전 문제(함정 주의 또는 잘못 꽂힌 책 찾기)
- 문제 위에 지금 구역(번호·이름·한 줄 설명)과 "구역 N / 10"을 보여 주고, 새 구역의 첫 문제에는 "새 구역 도착!"을 붙인다.
- 정답·오답 피드백과 해설은 문제마다 보여 준다 (PRD 필수).
- 구역의 2문제를 마치면 바로 그 구역을 완료로 저장한다. 다시 들어오면 마치지 않은 첫 구역부터 이어 간다.
- 10개 구역을 모두 마치면 게임 1단계 완료 → 2단계가 열린다.
- 문제는 탐험 단계에서만 푼다. 분류 도감에서는 영역 설명과 10개 구분표만 보여 준다.

## 화면 구성
- **탐험 지도** (`/map`): 탐험 단계(게임 1~4단계)를 고르는 화면. 단계를 마친 결과 화면, 시작 화면의 '이어하기'가 모두 이곳으로 돌아온다.
- **분류 도감** (`/codex`): 10개 주류 목록 → 영역을 누르면 쉬운 설명, 대표 주제(10개 구분표), 판단 힌트, 헷갈리기 쉬운 영역. 설명만 하고 문제는 내지 않는다.
- 상단 메뉴: 탐험 지도 · 분류 도감 · 오답 복습 · 설정

## 게임 2단계: 번호 속 비밀 풀기

번호 100개를 외우는 대신, 번호 안에 숨은 규칙을 발견하고 학생들이 자주 찾는 구역에 적용한다.

### 발견할 규칙
1. **둘째 자리는 더 좁은 주제** — 8 문학 → 81 한국문학
2. **언어와 문학은 나라 순서가 같다** — 710 한국어 ↔ 810 한국문학, 720 중국어 ↔ 820 중국문학, 730 일본어 ↔ 830 일본문학, 740 영어 ↔ 840 영미문학
3. **문학의 셋째 자리는 형식** — 1 시, 2 희곡, 3 소설, 4 수필 (예: 813 한국 소설, 843 영미 소설)
4. **역사의 둘째 자리는 대륙** — 910 아시아(911 한국), 920 유럽 … / 980 지리, 990 전기

### 구성 (src/data/level2.json)
- 규칙 4개를 차례로, 모두 15문제를 **이어서** 푼다 (규칙 1은 사회과학 포함 6문제, 규칙 2~4는 3문제씩).
- 문제 위에 지금 규칙(제목·설명, "규칙 N / 4")과 **문제 영역의 10개 구분표**(예: 축구 문제 → 600~690, 일본어 문제 → 700~790)를 보여 준다. 규칙의 첫 문제에는 "새 규칙 발견!"을 붙인다.
- 규칙 2~4에는 **🔑 숫자 해독표**를 크게 보여 준다: 언어·문학 둘째 자리(1 한국, 2 중국 …), 문학 셋째 자리(1 시, 2 희곡, 3 소설, 4 수필 …), 역사 둘째 자리(1 아시아, 2 유럽 … 8 지리, 9 전기). 규칙 데이터의 `key`에 적는다.
- **청구기호 순서 출제:** 문항마다 `callNumber`(그 문제가 다루는 번호)를 적고, 규칙 안에서는 이 번호 순서로 낸다 (예: 규칙 1 → 180, 440, 510, 690). 새 문항도 `callNumber`만 적으면 자리를 찾아 들어간다.
- 문항에 `"table": "main"`을 적으면 영역 구분표 대신 10개 주류표(000~900)를 보여 준다 (예: "510은 어느 큰 구역?").
- 구분표는 classifications.json의 강목(level 2) 데이터로 그린다. 명칭을 확인하지 못한 번호는 "확인 필요"로 표시한다.
- 규칙의 문제를 모두 마치면 그 규칙을 완료로 저장한다(`completedRules`). 4개를 모두 마치면 게임 2단계 완료 → 3단계가 열린다.
- 문항은 주류 영역(`classificationId`)에 연결한다. 구분표는 그 주류의 강목을 보여 준다.
- 모든 미션에서 '◀ 이전 문제 다시 보기'로 이미 푼 문제(내 답·정답·해설)를 다시 볼 수 있다. 답을 바꿀 수는 없고, 지금 문제의 입력은 그대로 남는다.

### 문제 형식
- 🔐 번호 조립: 숫자 카드를 눌러 빈칸을 채운다 (예: 일본어 회화 책 → 7□0 → 730). 지우기로 고칠 수 있다.
- 🧩 규칙 추리: "720이 중국어라면 820은?", "834는 어떤 책일까요?"
- 📦 손님 부탁 / 🧠 함정 주의: 1단계와 같은 상황형 (예: 번역본도 원작 언어의 문학 → 840)

## 게임 3단계: 저자기호 만들기

### 학습 목표
기호표를 외우는 것이 아니라 **만드는 방법을 이해**하고, 저자기호가 **저자 이름의 가나다순**으로 책을 줄 세우는 장치라는 것을 깨닫는다.

### 만드는 방법
저자 성 + 이름 두 번째 글자의 **자음 기호** + 같은 글자의 **모음 기호** + 책 제목 첫 글자의 **초성**

### 핵심 발견: 숫자는 소수로 읽는다
- 같은 성 안에서 저자기호 숫자는 **소수처럼 비교**한다: 최5 → 최52 → 최6 (최.5 < 최.52 < 최.6)
- 그래서 기호표의 숫자는 자음 순서를 그대로 지킨다: ㄱ 1 < ㄴ 19 < ㄷ 2 < ㄹ 29 < ㅁ 3 < … < ㅊ 8 < ㅋ 87 < ㅌ 88 < ㅍ 89 < ㅎ 9
- 결과적으로 저자기호 순서 = 저자 이름 가나다순. 같은 작가의 책은 제목 첫 글자 초성(ㄱ~ㅎ)으로 다시 줄 선다.

### 예시 책 (청소년이 많이 읽는 책, 저자기호는 제5표로 계산)

| 작가 | 책 | 이름 두 번째 글자 | 저자기호 |
|---|---|---|---|
| 이꽃님 | 당연하게도 나는 너를 | 꽃 (ㄲ 1, ㅗ 5) | 이15ㄷ |
| 이꽃님 | 세계를 건너 너에게 갈게 | 꽃 (ㄲ 1, ㅗ 5) | 이15ㅅ |
| 이꽃님 | 여름을 한 입 베어 물었더니 | 꽃 (ㄲ 1, ㅗ 5) | 이15ㅇ |
| 이미예 | 달러구트 꿈 백화점 | 미 (ㅁ 3, ㅣ 8) | 이38ㄷ |
| 이희영 | 페인트 | 희 (ㅎ 9, ㅢ 7) | 이97ㅍ |
| 한강 | 소년이 온다 | 강 (ㄱ 1, ㅏ 2) | 한12ㅅ |
| 한강 | 작별하지 않는다 | 강 (ㄱ 1, ㅏ 2) | 한12ㅈ |
| 손원평 | 아몬드 | 원 (ㅇ 6, ㅝ 6) | 손66ㅇ |
| 김초엽 | 우리가 빛의 속도로 갈 수 없다면 | 초 (ㅊ 8, ㅗ → ㅊ표 4) | 김84ㅇ |
| 김호연 | 불편한 편의점 | 호 (ㅎ 9, ㅗ 5) | 김95ㅂ |
| 황영미 | 체리새우: 비밀글입니다 | 영 (ㅇ 6, ㅕ 4) | 황64ㅊ |
| 백온유 | 유원 | 온 (ㅇ 6, ㅗ 5) | 백65ㅇ |

- 이15 < 이38 < 이97 은 이꽃님 < 이미예 < 이희영 (가나다순)과 같다.
- 김84(김초엽) < 김95(김호연): ㅊ < ㅎ
- 실제 학교 라벨과 다를 수 있다(도서관마다 저작표시 등 추가 규칙). 해설에 이 점을 적는다.

### 활동
- 🛠 저자기호 공방: 4칸(성 → 자음 기호 → 모음 기호 → 제목 초성)을 차례로 채워 완성. 기호표를 펼쳐 볼 수 있다.
- 🔢 줄 세우기 발견: 같은 서가(813.7) 작가 카드를 가나다순으로 세운 뒤 저자기호를 붙이면 순서가 그대로임을 확인한다.
- 🕵️ 실수 찾기: 흔한 실수(ㅊ 모음표를 잊음, 세 번째 글자를 씀, 숫자를 정수로 비교)로 만든 보기 중 바른 것 고르기
- 🔄 거꾸로 추리: "이15ㄷ을 쓴 작가는?"

### 1차에서 다루지 않는 경우
외국인 작가, 두 글자 성(남궁, 황보 등), 숫자·영문으로 시작하는 제목, 단체 저자

## 게임 4단계: 책 주소 완성하기

청구기호의 다섯 부분 (학습지 기준)

| 부분 | 예 | 뜻 |
|---|---|---|
| 별치기호 | R | 자료의 형태·이용 목적에 따라 별도 서가에 둘 때 그 장소를 나타냄 |
| 분류기호 | 813.7 | 자료의 주제 (게임 2단계) |
| 저자기호 | 이15ㄷ | 책을 쓴 사람 (게임 3단계) |
| 권차기호 | v.1 | 시리즈·전집의 권 번호 |
| 복본기호 | c.2 | 같은 책이 2권 이상일 때 몇 번째 책인지 |

### 활동
- 📇 라벨 해부: 라벨의 각 줄이 무엇인지 맞히기
- 🧱 라벨 조립: 책 정보 → 분류기호 + 저자기호 (+ v., c.) 를 합쳐 라벨 완성
- 📚 서가 정리: 책 5~6권을 청구기호 순서대로 꽂기. 순서: 별치기호 → 분류기호(소수점 포함) → 저자기호(성 가나다 → 숫자는 소수로 비교 → 제목 초성) → 권차 → 복본
- 🔎 실제 도서관 미션 (선택): 선생님이 등록한 학교도서관의 실제 책 찾기

## 데이터 원칙
- 분류기호·저자기호 규칙 데이터는 `needs-review`로 입력하고 선생님 확인 후 `approved`로 바꾼다.
- 실제 책의 청구기호는 학교도서관 목록에서 확인한 것만 쓴다. 연습 문제는 가상 예시 책을 쓰고 '가상 예시'로 표시한다.
- 저자기호는 규칙으로 계산되므로 실제 작가 이름을 써도 되지만, 실제 학교 라벨과 다를 수 있음을 해설에 적는다.
