# 📚 책길 탐험대 (v2) — 게임으로 배우는 도서관 책 찾기

> 미로 · 책꽂이 정리 · 외계인 · 벽돌 깨기 · 뱀 · 두더지!
> 고전게임 6가지로 **도서관 청구기호(KDC 제6판 + 이재철 저자기호)** 와 **책꽂이 순서 규칙**을 익히는 어린이용 웹 게임

---

## 🔒 개인정보 원칙

- 이름·별명 입력 없음, 순위표 없음.
- 브라우저(localStorage)에 남는 것은 **사서 선생님이 등록한 도서/문제 데이터**와 **소리 켬/꺼짐 설정**만입니다.
- 캐릭터(아바타), 이번 시간에 모은 별, 점수는 모두 메모리에만 있고 새로고침하면 사라집니다.
- 예전 버전이 남긴 이용자/점수 데이터가 있으면 첫 실행 때 자동으로 삭제합니다.

## 🎮 게임 6종

| 게임 | 원작 | 배우는 것 | 재미 요소 |
|---|---|---|---|
| 🧭 **미로 탈출** | 팩맨 | 주제 → 분류번호 찾기 | 별 조각 모으기, 먼지 도깨비 피하기, 출구 화살표, 20초 후 힌트 반짝임 |
| 📚 **책꽂이 정리** | 정렬 퍼즐 | 분류번호 → 저자기호 가나다 → 1권·2권 순서 | 드래그/탭 두 가지 조작, 칸마다 ✓✗ 즉시 표시, 3번 틀리면 정답 공개 |
| 👾 **외계인 격퇴** | 스페이스 인베이더 | 주제별 분류번호 빨리 찾기 | 모든 외계인이 같은 색(번호를 읽어야 함), 콤보, 도전 모드 폭탄 |
| 🧱 **벽돌 깨기** | 알카노이드 | 000~900 백 자리 구별 | 미션 벽돌은 1타, 나머지는 2타. 틀린 벽돌을 치면 "이 번호는 ○○" 알려줌 |
| 🐍 **책벌레 뱀** | 스네이크 | 청구기호 오름차순 | 다음 목표 반짝임, 먹을수록 몸 길어짐, 워프 이동, 스와이프 조작 |
| 🔨 **두더지 팡팡** | 두더지 잡기 | 저자기호 읽기, 순발력 | 세 번에 한 번은 정답 두더지 보장, 콤보, 뿅망치 커서 |

### 공통 재미 장치
- **3·2·1·출발!** 카운트다운과 조작법 안내
- **콤보**: 연속 정답마다 보너스 점수(최대 +100)와 효과음
- **스테이지 클리어 카드**: 정답과 "왜 그런지" 설명을 바로 보여주고 다음 문제로
- **힌트 토스트**: 틀리면 즉시 짧은 힌트가 화면 위에 뜸(게임은 계속)
- **별점(⭐ 최대 3개)** + 꽃가루 + 북이의 배움 카드(틀린 문제 다시 보기)
- **내 캐릭터**: 8가지 동물 중 선택 → 미로의 탐험가, 뱀 머리, 우주선 조종사, 막대로 등장
- **매번 다른 문제**: 등록 문제 일부 + KDC 분류표/도서 목록으로 자동 생성한 문제를 섞어 출제

## 📖 학습 내용

### KDC 제6판 10가지 큰 숫자
`000 총류` `100 철학` `200 종교` `300 사회과학` `400 순수과학` `500 기술과학` `600 예술` `700 언어` `800 문학` `900 역사`

### 이재철 저자기호
성(김) + 이름 번호(68) + 책 제목 첫 글자의 첫소리(ㅂ) → `김68ㅂ`

### 책꽂이 순서 5가지 규칙
1. 왼쪽 → 오른쪽, 위 칸 → 아래 칸
2. 분류번호 작은 것부터
3. 소수점은 한 자리씩 비교 (813.6 < 813.62 < 813.7)
4. 번호가 같으면 저자기호 가나다순
5. 1권 → 2권, c.1 → c.2

## ⚙️ 사서 선생님 화면

상단 메뉴 **사서 선생님** → 숫자 4자리 (기본 `1234`, [adminPanelScreen.js](src/components/adminPanelScreen.js)의 `checkPin` 에서 변경)

- **도서 자료 관리**: 우리 도서관 책 등록/삭제, 기본 16권 복원
  - 등록한 책은 미로(힌트), 책꽂이 정리(정렬), 두더지(저자기호) 문제로 자동 출제됩니다.
- **문제 검토**: 게임별 등록 문제 수 확인, 초기화
- **백업 & 복원**: 도서·문제 데이터를 JSON으로 내보내기/가져오기 (학생 정보 없음)
